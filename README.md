# Ashfall Camp — вертикальна анімація 9:16

`ashfall_camp_9x16.mp4` — 1080×1920, 30 fps, 24 с, H.264 + AAC стерео. Без тексту й логотипів.

| Час | Кадр | Звук |
|---|---|---|
| 0–8 с | Темно-червоне небо, зруйноване місто вдалині, дим, попіл; камера пролітає над руїнами | тривожний гул, вітер, далекий грім |
| 8–15.5 с | Пролітаємо над лісом і плавно опускаємось на галявину | вітер стихає, з'являється багаття |
| 15.5–20 с | Палатка біля вогнища, попіл падає на тент, всередині силует людини з чаєм при світлі ліхтарика | потріскування багаття |
| 20–24 с | Блискавка висвітлює небо й силует палатки, людина спокійно робить ковток; затемнення | грім, ковток чаю |

Усе згенеровано процедурно (Python, numpy, scipy, Pillow, ffmpeg):

```bash
python3 render.py            # відео → out/video_only.mp4 (~10 хв на 4 ядрах)
python3 audio.py             # звук → out/soundtrack.wav
ffmpeg -i out/video_only.mp4 -i out/soundtrack.wav -c:v libx264 -crf 23 -c:a aac -b:a 192k -shortest ashfall_camp_9x16.mp4
python3 render.py --preview 0.5 4 16 20.7   # окремі кадри PNG для перевірки
```
