# Безодня: що ховається на дні океану

`bezodnya_16x9.mp4` — 1920×1080, 24 fps, ~8:04, H.264 + AAC стерео. 32 сцени, українська озвучка,
глибиномір 0 → 10 935 м у правому верхньому куті, субтитри по 3–5 слів, великі числа по центру.

## Озвучка

- Модель: відкрита українська TTS [ukrainian-tts](https://github.com/robinhad/ukrainian-tts) v6
  (Tacotron2 + HiFi-GAN), голос «Микита». ElevenLabs не використовувався.
- **Наголоси розставлені вручну в кожному слові** (`voice_script.py`, `+` перед наголошеною
  голосною). Модель читає наголос рівно там, де він позначений, без автоматичного вгадування.
- Настрій по фразах: `calm` (документальний), `soft` (тихіше й повільніше на моторошних
  моментах), `tense` (хук і тріск скла). Паузи: між реченнями ~0,4 с, на «…» ~0,7 с.
- Кожна фраза синтезується до 3 разів; береться дубль із найприроднішим темпом (відсікає збої).
- Обробка (`build_timeline.py`): rubberband (темп за настроєм, тон −1 півтон зі збереженням
  формант — глибший тембр), EQ, компресія, легка кімната, нормалізація гучності.
- `narration_uk.md` — той самий текст для ElevenLabs (наголоси акутом), якщо захочеться
  переозвучити їхнім голосом.

## Як зібрати

```bash
# 1) голос (Python 3.10, espnet==202301, torch 2.0; модель з релізу v6.0.0 ukrainian-tts)
cd MODEL_DIR && python tts.py MODEL_DIR VOICE_DIR mykyta
# 2) таймлайн, обробка голосу, субтитри/глибиномір (Python 3.13: numpy, scipy, pillow)
python build_timeline.py VOICE_DIR OUT
# 3) відео (32 сцени, ~35 хв на 4 ядрах) і звук
python render_video.py OUT/timeline.json RENDER --workers 4
python audio_mix.py OUT
# 4) зведення
./make_final.sh RENDER OUT bezodnya_16x9.mp4
```

Візуал процедурний (numpy + Pillow), без нейромереж для відео: стилізована 2.5D-анімація
з об'ємним світлом прожекторів, морським снігом і біолюмінесценцією.
