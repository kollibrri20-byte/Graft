# Село, якого немає на жодній карті — збирання відео

Слайд-шоу на ~6 хв: 119 кадрів, кожен під своє речення озвучки, у постійному русі.

## Що покласти

```
village/
  frames/001.jpg … 119.jpg   ← картинки (jpg/png/webp, будь-який розмір; кроп до 16:9 по центру)
  voice.mp3                  ← озвучка цілком (або voice.wav / .m4a / .ogg / .flac)
```

## Запуск

```bash
pip install -r requirements.txt     # + ffmpeg у системі
python3 assemble.py                 # → out/selo.mp4 (1920×1080, 30 fps, H.264 + AAC)
```

Чорновий рендер удвічі меншого розміру: `python3 assemble.py --scale 0.5`.
Окремі кадри для перевірки: `python3 assemble.py --preview 12 95.5` → `out/preview_*.png`.

## Що робить скрипт

- **Таймінги.** Запис ділиться паузами на шматки мовлення, далі вони групуються в 119 речень за кількістю складів (довгі паузи = межі речень, короткі = коми). Результат пишеться в `out/timings.csv`. Якщо якийсь кадр з'являється не там, виправ `start`/`end` у файлі й запусти `python3 assemble.py --timings out/timings.csv`.
  Без озвучки тривалість кадру береться з довжини речення (2–5 с).
- **Камера.** Наїзд, від'їзд, панорами вліво/вправо, нахили вгору/вниз, діагональні наїзди; напрямки чергуються й не повторюються підряд. Макро- та надкрупні плани повільно наїжджають; кадри «з висоти» відїжджають або панорамують; у кадрах з «Dutch angle» камера ще й трохи нахиляється. У погоні (кадри 73–83) працює «ручна» камера.
- **Світло.** Кадри зі свічками, ліхтарями й ліхтариком мерехтять помітно, інші — ледь-ледь.
- **Переходи.** Між реченнями — м'який перехресний перехід 0,5 с; перед кожним «Розділом…» — затемнення через чорне. Відео починається з появи з темряви й закінчується затемненням після «Вона усміхалася».
- **Плівка.** Віньєтка й легке зерно.
- **Звук.** Голос нормалізується до −16 LUFS. Під ним тихий ембієнт (вітер і низький гул), який автоматично притихає під голос; на початку розділів звучить глухий удар. Вимкнути: `--no-ambient`.
- **Заглушки.** Якщо картинки бракує, малюється темна картка з номером і реченням, тож порядок і ритм можна перевірити ще до генерації всіх кадрів.

Промти й тексти всіх кадрів лежать у `shots.txt` (формат: `номер | речення | промт`).
